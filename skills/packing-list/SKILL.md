# Сбор чемодана: что взять с собой

Сначала уточни **направление, сезон, длительность и формат** (пляж/город/горы/поход) — список сильно зависит от этого.

## Базовый список (любая поездка)

### Документы и деньги
- [ ] Паспорт (+виза), копии и фото документов офлайн
- [ ] Билеты и брони (распечатка + офлайн в телефоне)
- [ ] Страховой полис и телефон ассистанс-службы
- [ ] Банковские карты (основная + резервная) и немного наличных
- [ ] Водительские права (если нужна аренда авто)

### Электроника
- [ ] Телефон + зарядка, повербанк
- [ ] **Переходник для розеток** (тип зависит от страны!)
- [ ] Наушники, при необходимости — ноутбук/планшет

### Гигиена
- [ ] Зубная щётка/паста, дезодорант, расчёска
- [ ] Средства до 100 мл в ручную кладь (правило жидкостей)
- [ ] Солнцезащитный крем (SPF под направление)
- [ ] Влажные салфетки, антисептик для рук

### Аптечка
- [ ] См. отдельный скилл `travel-medkit`

## Одежда по климату

| Климат | Что добавить |
|---|---|
| Жаркий/пляж | Лёгкая одежда, головной убор, очки, купальник, сланцы, лёгкая кофта на вечер/кондиционеры |
| Холодный/горы | Слои (термобельё + флис + мембрана), шапка, перчатки, непромокаемая обувь |
| Город/межсезонье | Удобная обувь для ходьбы, дождевик/зонт, один нарядный комплект |
| Тропики/дождь | Быстросохнущая одежда, дождевик, защита от насекомых |

## Правила упаковки

- **Слои, а не объём:** несколько тонких вещей универсальнее одной тёплой.
- **Тяжёлое — вниз и к спинке** чемодана; обувь — в мешки.
- **Ручная кладь:** документы, лекарства, зарядка, смена белья, ценное — всегда с собой, не в багаже.
- **Жидкости:** в ручной клади — ёмкости ≤100 мл в прозрачном пакете.
- Оставь **10–15% свободного места** под покупки.

## Частые «забывалки»

Переходник для розеток · повербанк · зарядки · солнцезащита · очки/линзы и раствор · личные лекарства с запасом · копии документов · дождевик.

## Анти-паттерны

- Класть лекарства и документы только в сданный багаж (могут потеряться/задержаться).
- Брать жидкости >100 мл в ручную кладь.
- Игнорировать тип розеток в стране назначения.
- Перегружать чемодан «на всякий случай» — превышение веса дороже докупить на месте.
